# Image credits — Lexal Tech Store

All photos in `public/img/` are royalty-free Unsplash equivalents in Pinterest-style tech aesthetic,
used because Pinterest requires login and most Pinterest pins are copyrighted.

If you want exact Pinterest images:
1. Download the pin image manually from Pinterest.
2. Drop it into `public/img/products/` (e.g. `watch.jpg`).
3. Update `src/data/products.js` `imageUrl` if the filename differs.
4. Restart the app — existing DB rows auto-migrate `.svg` → `.jpg`.
